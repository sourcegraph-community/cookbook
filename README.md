# Cookbook

Runnable code from Sourcegraph videos and blog posts. One directory per recipe, each with its own README. Clone it, read the recipe you came for, run it.

## Recipes

| Recipe | What it shows | Video |
| --- | --- | --- |
| [search-jobs-api](search-jobs-api/) | Run an exhaustive Search Job over the Sourcegraph API and download the results as JSONL | [Watch](https://www.youtube.com/watch?v=Dh-7dZuS89M) |

## Adding a recipe

- One directory per recipe, named for the thing it demonstrates.
- A README that stands on its own, so nobody has to watch the video to run the code.
- No dependencies unless the recipe is about the dependency.
